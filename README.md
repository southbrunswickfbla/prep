# FBLA Prep

AI practice tests for South Brunswick High School FBLA members. Members sign in with their school Google account, drill any objective-test event 10 questions at a time, take full 100-question practice tests, and get their weakest topics drilled until they improve.

- Website: React 19, TypeScript, Tailwind v4, React Router, Vite. Published to GitHub Pages.
- Backend: Google Apps Script (`backend/Code.gs`) with a Google Sheet for storage and the Gemini API free tier for writing questions.

See **SETUP.md** to put it online. Run `npm run dev` to preview it in demo mode.
