# FBLA Prep

AI practice tests for South Brunswick High School FBLA members: all 45 FBLA events with an objective test, built from the official 2026–27 guidelines. Members sign in with their school Google account, pick a level (RCE, SLC, or NLC), read AI study guides for each topic, drill 10 questions at a time, take full 100-question practice tests, and review every question they missed until they get it right. Officers see chapter-wide readiness by event.

- Website: React 19, TypeScript, Tailwind v4, React Router, Vite. Published to GitHub Pages.
- Backend: Google Apps Script (`backend/Code.gs`) with a Google Sheet for storage and the Gemini API free tier for writing questions.

See **SETUP.md** to put it online. Run `npm run dev` to preview it in demo mode.
